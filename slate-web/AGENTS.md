# Slate Web

A high-performance whiteboard and intelligent note-taking application powered by an independent AI architecture.

## AI Capabilities
- **Direct Multi-Provider Support**: Connects directly to Google Gemini or OpenAI using client or server-side API keys.
- **Offline AI Assistant**: Heuristic intelligence engine requiring zero API keys for note summarization, active-recall flashcard generation, multi-choice quizzes with explanations, mind-map hierarchical structuring, math formula parsing, and flowchart synthesis.
- **Local RAG & Semantic Search**: Client-side TF-IDF + 3-gram character embedding index over all boards and notes.
- **Visual Intelligence**: Handwriting-to-text, handwritten math recognition, diagram-to-flowchart conversion, and full canvas "Explain Board" analysis.
- **Document Intelligence**: PDF and document viewer with automatic summarization, quiz generation, and flashcard extraction.
